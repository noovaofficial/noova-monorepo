# Noova — контекст проекта для разработки

Каталог-классифайд анкет для взрослых (18+), легальная модель для рынка Германии
(само-размещение анкет, не брокерская витрина). Дальше — расширение на другие
легальные юрисдикции. Ниже — всё, что нужно, чтобы продолжить фронтенд в IDE.

---

## 1. Файлы, которые уже есть

> Прототипы — исторический референс. Рабочий код живёт в `apps/`,
> актуальная структура описана в [README](../../README.md).

| Файл | Что это |
|------|---------|
| `apps/web/src/styles/tokens.css` | Источник правды по цветам/типографике/отступам. Светлая тема в `:root`, тёмная в `[data-theme="dark"]`. |
| `documentation/arch/prototypes/noova_design_system.html` | Живой style guide: свотчи, шкала шрифтов, превью компонентов. Референс, в прод не идёт. |
| `documentation/arch/prototypes/noova_home.html` | Исходный прототип главной. Перенесён в `apps/web/src/app/[locale]/page.tsx`. |
| `documentation/arch/prototypes/noova_profile.html` | Исходный прототип страницы анкеты. Перенесён в `apps/web/src/app/[locale]/profile/[slug]/page.tsx`. |

Все прототипы самодостаточны: токены вшиты в `<style>`, тема по умолчанию — тёмная
(`<html data-theme="dark">`). Шрифты — Google Fonts (Sora + Inter) через `@import`.

## 2. Дизайн-принципы

- **Приглушённо, не ярко.** Бренд-розовый — только акцент (кнопки, выбранные чипы,
  ключевые бейджи). Основная масса экрана нейтральная, тёплая (плам-оттенок).
- **Тёмная тема — дефолт.** Каталог фото-ориентированный: на тёмном фоне снимки «играют»,
  интерфейс уходит на второй план.
- **Переключение темы — один атрибут** `data-theme` на `<html>`. Все значения — через
  CSS-переменные, ничего не хардкодить мимо токенов.
- **Фото — только заглушки-градиенты** в прототипах (реальных изображений нет).
  Внизу карточки/фото — скрим (`--overlay`), чтобы имя/город читались поверх любого фото.

## 3. Токены (сокращённо; полный список — в `apps/web/src/styles/tokens.css`)

### Бренд
`Rose #E0457B` · `Coral #FF8A5C` · `Plum #1E1320` · `Off-white #FBF4F0`

### Семантические (light → dark)
- Поверхности: `background` `#F6F1EF`→`#150E14`, `surface` `#FFFFFF`→`#1F1620`,
  `surfaceMuted` `#F0E9E7`→`#2A1F2C`, `surfaceSunken`, `overlay`.
- Текст: `primaryText` `#251A24`→`#F4ECF1`, `secondaryText` `#6E5F6A`→`#B6A6B1`,
  `tertiaryText`, `textOnBrand`, `link`.
- Границы: `border` `#E7DDDA`→`#352A37`, `borderStrong`, `borderFocus`.
- Бренд: `primary` `#E0457B`→`#EC5A8B`, `primaryHover`, `primaryActive`,
  `primarySubtle`, `onPrimarySubtle`.
- Акцент: `accent` `#FF8A5C`→`#FF9A70`, `accentHover`, `accentSubtle`.
- Статусы: `success` `#3E9E7A`, `warning` `#C98A2E`, `danger` `#CE4640`,
  `info` `#6E78B0` (каждый + `…Subtle`).
- Продуктовые: `verified` `#2E8B9E` (бейдж «Проверено»), `featured` `#C29A33`
  («ТОП»/промо), `online`.
- Тени: `shadowSm / shadowMd / shadowLg`.

### Типографика
- Display / заголовки: **Sora** (600–700).
- Body / UI: **Inter** (400–600).
- Шкала: `xs 12` `sm 14` `base 16` `lg 18` `xl 20` `2xl 24` `3xl 30` `4xl 38` `5xl 48`.
- Line-height: `tight 1.1` (hero) → `relaxed 1.65` (FAQ/описания).

### Раскладка
- Отступы: сетка 4px (`space1…space16`).
- Радиусы: `Sm 6` (теги) · `Md 10` (кнопки/инпуты) · `Lg 16` (карточки) · `Xl 24` ·
  `Pill 999` (чипы/бейджи).
- Контейнер: `--containerMax: 1200px`, паддинг `0 32px` (мобилка `0 18px`).
- Сетка карточек: `repeat(auto-fill, minmax(200px, 1fr))`, gap 18px (≈5 в ряд на десктопе).

## 4. Компоненты (классы из прототипов → компоненты React)

| В прототипе | React-компонент | Заметки |
|-------------|-----------------|---------|
| `header` (2 строки) | `<Header>` | row1: лого + Войти/Создать; row2: Фильтры + быстрые чипы + `langBtn` + `themeBtn`. Липкий, `backdrop-filter`. |
| `.promo` | `<PromoSlider>` | горизонтальный scroll-snap, стрелки, метка «Реклама». |
| `.grid` + `.card` | `<ProfileGrid>` / `<ProfileCard>` | фото 3/4, бейджи ТОП/Проверено, онлайн-точка, теги, цена, hover-подъём. |
| `.section-card` | `<Section>` (collapsible) | шапка + `chev`; сворачивание классом `.collapsed`. |
| `.gallery` | `<Gallery>` | главное фото + лента миниатюр, клик по миниатюре меняет главное. |
| `.params` | `<ParamsList>` | key/value в две колонки. |
| `.prices` | `<Prices>` | карточки 1 час / 2 часа / Ночь, «У себя» / «Выезд». |
| `.svc-grid` | `<Services>` | группы услуг с чек-иконкой, флажок «доп». |
| `.trust` | `<VerifiedBadge>` / trust-блок | акцент на верификации возраста/личности. |
| `footer` | `<Footer>` | лого + текст 18+ + «Компания» + Impressum/Datenschutz/AGB. |

Общие атомы: `.btn` (`btn-primary` / `btn-secondary`), `.iconbtn`, `.chip-f`
(с `.sel`), `.tag`, `.badge` (`verified` / `featured`), `.dot` (онлайн).

## 5. Интерактив в прототипах (перенести на состояние во фреймворке)

- **Переключение темы** — `data-theme` на `<html>`, иконка солнце/луна.
- **Переключение языка** — сейчас минимальный демо-i18n (RU⇄EN). В проде — нормальная
  i18n-библиотека (напр. `vue-i18n` / `react-i18next`), строки вынести из разметки.
- **Галерея** — свап главного фото по клику на миниатюру.
- **Секции** — сворачивание/разворачивание.
- **Избранное** — тоггл `active` на кнопке.

Карточки в прототипах генерируются JS-ом из массивов-заглушек — это временно, заменить
на данные с API.

## 6. Продуктовые ограничения (важно для разработки)

- **Только 18+.** Гейт по возрасту, бейдж «Проверено» — часть основного UX доверия.
- **Верификация** возраста и личности — обязательный шаг, без неё анкета не публикуется.
- **Германия:** нужны `Impressum`, `Datenschutz` (GDPR), `AGB` — уже заложены в футере.
  Персональные данные анкет — особая категория, хранить с усиленной защитой.
- **Само-размещение**, а не брокерская витрина (чтобы не требовалась лицензия
  «Vermittlung» по немецкому праву).
- **Портируемость инфраструктуры** важнее «ухода в тень»: контейнеры/IaC для быстрого
  редеплоя, запасные домены, PWA вместо стора, высокорисковые платёжные процессоры
  (CCBill/Verotel/SegPay) + крипто-фолбэк.
- Реальные фото — только после верификации; в прототипах везде заглушки.

## 9. Технические заметки

- **Артефакты/песочница:** `localStorage`/`sessionStorage` в артефактах не работают —
  состояние держать в памяти (в реальном приложении ограничение неактуально).
- **CSS:** `aspect-ratio` и `grid auto-fill` требуют современного браузера
  (в старых движках рендерятся некорректно — это норма).
- **Шрифты:** Sora + Inter с Google Fonts; для прода лучше self-host (woff2) ради
  скорости и приватности.
- **Тема:** дефолт — тёмная; светлая полностью готова, переключается атрибутом.
